### Check Device Test authority before binding activation

The Agent checks installed Device authority through a separate Device Test
permit. A previous passed test is not required for this permit. Business Device
Work still requires its passed test and active Binding Revision.

Windows firmware remains `unavailable` when the spooler cannot observe it. The
signed Hardware Certification Matrix must contain the same value for the exact
Device. Missing facts and observed firmware changes continue to block admission.
